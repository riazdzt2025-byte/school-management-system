Getting a new subject onto a result sheet
  1. Assign the subject here (Office → Subject Assignments): pick the Institution, Class and Group, then either choose an existing subject or create a new one in the same form. {% if not perms.students.add_subjectrequirement %}— you can view this page but not change it; ask the Office department.{% endif %}
  2. Optional subjects only: record each student's choice (Office → Students → Edit student). Mandatory and the student's own religion paper are added automatically — no choice needed.
  3. Set the marks distribution {% if perms.students.change_subject %} under Exam → Mark Evaluation: Full Marks, CQ / MCQ / Practical / Weekly Test, Pass % and the Count tick. {% else %} under Exam → Mark Evaluation — ask the Exam (or Office) department; you do not have permission to change it. {% endif %} Without a row here the subject's own defaults are used.
  4. Enter the marks {% if perms.students.add_exammark %} from Exam → Enter Marks, or import one subject's Excel sheet from the exam's Import page. {% else %} from Exam → Enter Marks — ask the Exam (or Accounts) department. {% endif %}
  5. Check and publish: open the Result Sheet from the exam list, then Publish there. A result page only opens for a published exam.

Why are there two religion rows (Islam & Moral Education and Hindu Religion & Moral Education)?
Religion is a conditional subject: the system automatically picks the one paper that matches each student's own religion — Hindu students sit Hindu Religion & Moral Education, every other student sits Islam & Moral Education. Both rows must be assigned so every student has a paper; marks entry and the Excel import offer each student only their own paper. On the result sheet the two papers are one Religion column (REL), not two — each student's cell shows their own paper, and a student whose paper is not assigned gets a dash that is never counted.

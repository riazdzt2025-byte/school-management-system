# AGENTS.md — Project Instructions

## ⚠️ User Preference (IMPORTANT — always follow)

**Always deliver HTML files to the user. Do NOT give Python (.py) files.**

- The user finds HTML files much easier to use and understand.
- When creating scripts, tools, reports, guides, or any deliverable for the user → make a single self-contained **HTML file** (inline CSS/JS) and present it.
- Do not create standalone Python files for the user to run.
- If a Python script is needed internally (e.g., for data processing), keep it out of the way and present the result as HTML instead.

## Project Context

- School Management System built with **Python + Django 6.1**, SQLite/PostgreSQL, Bootstrap 5.
- Deployed on Render: https://school-management-system-27mn.onrender.com/
- The user communicates in **Bengali** — reply in Bengali.
- The user is learning programming from zero; keep explanations simple, step-by-step, and encouraging.

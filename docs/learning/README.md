## শুরু করার ক্রম

1. `skills-test-bn.html` ব্রাউজারে খুলুন (ইন্টারনেট ছাড়াই চলে), টেস্ট দিন, ফলাফলের স্ক্রিনশট রাখুন।
2. `curriculum-bn.html`-এ "প্রথম ৭ দিন" অংশটুকু আগে করুন — এগুলো কোডিং নয়, দায়িত্ব।
3. `labs-bn.html`-এর Lab 0 (সিস্টেম চালু) → Lab 1 (টেস্ট) → Lab 11 (ব্যাকআপ ড্রিল)।
   এই তিনটি শেষ হলেই আপনি **লেভেল ১ (অ্যাডমিনিস্ট্রেটর)**-এর পথে।
4. প্রতি ল্যাব শেষে `evidence.md`-এ এক লাইন যোগ করুন। ৬ মাস পরে এটাই আপনার সিভি।

## নিরাপত্তার নিয়ম (সব ল্যাবে)

- প্রোডাকশন ডেটাবেসে কখনোই কোনো ল্যাব নয়।
- শুরুতে কপি: `cp db.sqlite3 db.lab.sqlite3` এবং প্রয়োজনে `DATABASE_URL` দিয়ে সেটাই ব্যবহার করুন।
- `flush`, `delete`, `restore_backup --yes` — শুধু ল্যাব কপিতে, ব্যাকআপ নিয়ে।

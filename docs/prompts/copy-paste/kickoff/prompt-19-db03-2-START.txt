৪. কাজ:
   - env flag ডিজাইন করো (যেমন RATE_LIMIT_CACHE বা CACHE_URL) — default থাকলে dev behaviour
     (LocMem) অপরিবর্তিত থাকতে হবে। production-এ Redis বা Django DB cache backend সেট করা
     যাবে (owner সুপারিশ: Redis না থাকলে DB cache, নতুন paid service নয়)।
   - lockout threshold অপরিবর্তিত রাখো।
   - students/test_rate_limiting.py-তে (না থাকলে existing rate-limit টেস্ট ফাইল খুঁজে বের করে
     সেখানে) টেস্ট যোগ করো: counter persist হয় cache backend অনুযায়ী, reset behavior ঠিক,
     limit exceeded হলে lock হয়।

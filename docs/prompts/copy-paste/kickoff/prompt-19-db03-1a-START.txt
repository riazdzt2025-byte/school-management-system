৩. স্কোপ (শুধু আজকের কাজ, পুরো DB-03 নয় — "Student core" route-গুলো):
   add_student, edit_student, delete_student, student_list, student_detail, archived_students,
   bulk_delete_students, bulk_update_students, bulk_update_select, restore_student,
   bulk_purge_archived_students, purge_archived_student, discontinue_student,
   download_student_list, import_students, download_import_template, auto_register_students,
   student_promotion, student_promotion_history, rollback_student_promotion, student_by_id,
   student_exams, student_result_detail, student_id_card।

   প্রতিটা route-এর জন্য কোড থেকে (অনুমান নয়) যাচাই করো:
   - login guard আছে কি (anonymous হলে 302 login)?
   - permission guard আছে কি (permission ছাড়া হলে 403)?
   - department guard আছে কি (ভুল department হলে 302 dashboard)?
   - institution scope guard আছে কি (students/permissions.py-এর কোন helper ব্যবহার হচ্ছে —
     _institutionally_scoped/_scoped_institution_ids/_get_scoped_object_or_404/
     _scope_by_allowed_institutions/_scope_institution_qs/_scope_write_queryset ইত্যাদি;
     cross-institution হলে 404/খালি ফলাফল)?

   ফাঁক পেলে smallest coherent fix + negative test যোগ করো — actual HTTP request দিয়ে
   302/403/404 assert করে, students/test_institution_isolation.py বা
   test_institution_write_isolation.py-তে (নতুন টেস্ট ফাইল বানিয়ো না, existing-এ যোগ করো)।

## ২. আগের অবস্থা → এখনকার অবস্থা

**আগে (যাচাই করা):** shortcut ছিল, কিন্তু (ক) permission না থাকলেও `data-subject-pk`, `data-enter-marks-base`, `data-shortcut-url` ও JS HTML-এ যেত (শুধু `data-shortcut-disabled` + "Ask Exam dept" tooltip) — অর্থাৎ লুকানো URL; (খ) JS Ctrl/Cmd-এর সঙ্গে Shift/Alt, middle/right-click, keyboard activation ও touch-generated click-ও গ্রহণ করত; (গ) rank row-এর ভেতরের link-এ Ctrl+Click করলে নিজের native আচরণের বদলে correction খুলত; (ঘ) keyboard/mobile ব্যবহারকারীর জন্য দৃশ্যমান পথ ছিল না।

**এখন:**
- `result_sheet.html` / `full_rank_list.html`: `add_exammark` **এবং** published না হলে কোনো `data-*`, URL, tooltip hint, notice, link বা `<script>` render হয় না; view-ও `enter_marks_base_url`/`marks_entry_url` খালি করে।
- JS: শুধু primary-button Ctrl/Cmd+click, Shift/Alt ছাড়া, mouse pointer (touch/pen/`firesTouchEvents`/`detail===0` বাদ); `a/button/input/select/textarea/label`-এর ভেতরে native আচরণ; `opener.noopener`।
- দৃশ্যমান fallback: toolbar-এ **Correct marks (choose subject)** (`target=_blank rel=noopener`, group সহ, `d-print-none`), শুধু permission+published থাকলে।
- Published lock অপরিবর্তিত: খোলা `enter_marks` পেজ locked থাকে, unlock ছাড়া write refuse + audit।

## ৩. Edge-case নির্ধারণ

| কেস | আচরণ |
|---|---|
| Plain click / print | কিছু না |
| Ctrl/Cmd + left-click | নতুন tab-এ `enter_marks` (বা rank-list-এ chooser) |
| Shift, Ctrl+Shift, Cmd+Alt, middle, right, keyboard, touch/pen | কিছু না, `preventDefault` নয় |
| Unpublished exam | দুই পেজই `exam_list`-এ redirect — shortcut-ই নেই |
| Group-less exam / fixed-group exam | `data-group=""` → URL-এ `?group=` যোগ হয় না; exam-এর নিজের group `enter_marks`-এ প্রযোজ্য |
| Religion cell | student-এর নিজের paper pk (অপরিবর্তিত) |
| Cross-institution exam id | `result_sheet`/`full_rank_list`/`select_marks_subject`/`enter_marks` GET+POST → 404, কিছু save হয় না |
| Exam-এ unassigned subject pk | redirect `select_marks_subject`, কিছু save হয় না |

## ১. আগের অবস্থা → এখনকার অবস্থা

**আগে:** boost code ছিল, কিন্তু `round(sum(gpa_points) / len(gpa_points), 2)` Decimal-context rounding-এর উপর নির্ভর করত। ফলে policy-র critical step—raw GPA কে দুই দশমিকে আনার নিয়ম—একটি named, testable contract ছিল না। Existing test শুধু exact 4.90 ও exact 5.00 pin করত; boundary, cap, F/AB guard, relative position ও cross-surface proof ছিল না।

**এখন:** `calculate_passing_gpa()` একমাত্র final-GPA helper। Pass branch-এ subject-point average-কে `Decimal.quantize(Decimal('0.01'), ROUND_HALF_UP)` করে, 5.00-এ cap করে, এবং rounded `[4.90, 5.00)`-কে 5.00/A+ করে। Fail/No Marks branch helper-এ যায় না। Owner ২০২৬-০৯-২৩ নিশ্চিত করেছেন: 4.895→4.90→boost, two-decimal display, এবং অন্য সব subject pass হলে A/4.00 subject থাকলেও eligibility।

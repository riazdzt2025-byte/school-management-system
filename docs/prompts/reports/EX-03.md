## ১. আগের অবস্থা → এখনকার অবস্থা

**আগে:** `SubjectMarkSetting` = `institution + admission_class + subject + exam_type` unique; **group field নেই**। একই class + exam_type-এ SCI/ARTS আলাদা full marks / parts / pass % দেওয়া অসম্ভব — দ্বিতীয় row unique-ভঙ্গ (IntegrityError) হতো। `get_subject_marks(exam, subject)` শুধু class+exam_type দেখে, group অগ্রাহ্য; `active_exam_subject_ids` group-অজ্ঞ; marks entry/import ও result একই config পেত, group-ভেদ বোঝাত না। `mark_evaluation_settings` UI-এ group selector ছিল কিন্তু save-এ group ignore হতো; validation (parts exact/weekly/group) ছিল না; `mark_entry` group-mismatch subject লুকাত কিন্তু marks config group-ভেদ মানত না।

**এখন:** পুরোপুরি **group-aware** (EX-03):
- **Model:** `SubjectMarkSetting.group` (`CharField(choices=GROUP_CHOICES, blank=True, default='')`, help: blank = সব group-এ default) + uniqueness `institution+admission_class+subject+exam_type+group` (নতুন migration **0044** remove old → add field → alter pass%/full_marks validator → add new constraint). `clean()` → group blank for <9, pass 0–100, full>0; parts/weekly model-এ permissive (legacy mismatched allow, view-এ strict); `save()` → <9 হলে group clear + `full_clean()`.
- **Resolution chain (এক ফাংশন):** `result_utils.get_subject_marks(exam, subject, group=None)` → effective_group → group-specific row → blank-group default → Subject global defaults (class zero-padding tolerant, exam.spelling preferred). `resolve_mark_setting()` helper একই chain low-level. `active_exam_subject_ids(exam, subject_ids, group=None)` → group-aware active check (exact group → blank fallback). `get_exam_subjects()` এখন group-aware active; `build_exam_results()`/`failed_subject_rows`/`section_arrangement` group param দিয়ে `get_subject_marks(..., group=group)` ও `ReligionColumn.header_marks_config(..., group)`.
- **Marks entry/import:** `import_exam_marks`, `enter_marks`, `download_marks_import_template` `get_subject_marks(..., group=selected_group)`; `build_subject_marks_workbook(..., group)` ও `parse_subject_marks_workbook(..., group)` group-aware; `result_sheet` sheet_columns header group-aware.
- **UI (`mark_evaluation_settings`):** group selector + per-group listing (exam_like without exam_type → inactive subjects still listed for re-enable); SAVE validation: full>0, pass 0–100, group rule (<9 blank), weekly only MID (error & skip), parts exact equality (error & skip, owner-সিদ্ধান্ত), duplicate (unique constraint → ValidationError), clear error messages; `record_audit` on save/update; institution scoping `_resolve_requested_institution` + `_scope_by_allowed_institutions` অপরিবর্তিত; weekly_test column **শুধু MID_TERM_1/2/3-এ render** (view `show_weekly_test` flag + template conditional + help-text mention; non-MID-এ POST-এও reject — legacy stored value DB-এ থাকে, display হয় না).
- **Backward compat:** পুরোনো row group='' → সব group-এ default হিসেবে কাজ করে; migration ডেটা হারায় না; বিদ্যমান 0043-পরবর্তী data ভাঙে না.

## ৪. যা যাচাই হয়নি / বাকি ঝুঁকি

- **Concurrency:** দুই ব্যবহারকারীর একসাথে শেষ আসন/একই roll — কোডে lock আছে, কিন্তু আসল parallel test নেই; Postgres-এ CI-র মাধ্যমে শুধু suite চলবে।
- **Add Student form-এর capacity race:** form-এর `has_room` এখনো lock করে না (শুধু approval ও import lock করা হয়েছে)। একই নীতিতে বাড়ানো যায়; এই সেশনে scope-এর বাইরে রাখা হয়েছে।
- **Student ID:** import-এ ID column নেই, auto-generate হয় (unique)। ইতিমধ্যে ID-এর একটি concurrent collision সম্ভব (count-ভিত্তিক) — row error হিসেবে ধরা পড়ে, silent নয়; বিস্তারিত রাখা হলো।
- **Import partial failure:** প্রতি row আলাদা commit (আগের নকশা)। একটি row ব্যর্থ হলে আগের row থাকে — এটি ইচ্ছাকৃত row-level নীতি; “সব বা কিছুই নয়” চাইলে owner সিদ্ধান্ত লাগবে (এই সেশনে বদলানো হয়নি)।
- **Import class validation:** class-কে institution-এর configured class list-এর সাথে মেলানো হয় না (form-ও করে না) — নীতি বদলানো হয়নি।
- **Marks import:** sheet-এর নাম বা subject code যাচাই হয় না; অন্য subject-এর CQ/MCQ/PT-সমৃদ্ধ ফাইল সঠিক header দিয়ে এলে ভুল subject-এ যেতে পারে (পূর্বের নকশা; teacher-এর ফাইল নির্বাচনের ওপর নির্ভর)।
- **Postgres / live Render / আসল ডেটা:** চালানো হয়নি। কোনো production DB/credential ছোঁয়া হয়নি।

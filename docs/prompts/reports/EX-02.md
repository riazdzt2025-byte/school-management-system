## ১. আগের অবস্থা → এখনকার অবস্থা

নিয়ম (এই সেশনে আনুষ্ঠানিক): **register/roll-ভিত্তিক output = numeric roll order (roll_no → name → pk; None সবার শেষে); merit/rank output = position order।**
`Student.roll_no` হলো `IntegerField` ⇒ SQL-এ sort-ই numeric — string-trap (`'10' < '2'`) কোডে ছিলই না; আসল ফাঁক ছিল **NULL-first** (SQLite ও Postgres ASC-তে NULL আগে আসে) এবং অসম্পূর্ণ tie-break।

## ১. আগের অবস্থা → এখনকার অবস্থা

**আগে (baseline — PROGRESS row 06):** নীতি ইতিমধ্যে **Complete** — এক source (`result_utils.compute_subject_result` + `build_exam_results`), blank = F + 0 counted (`EXAM_ABSENT_SUBJECT_FAILS=True` default), all-blank = `No Marks` unranked, entered 0 = counted Fail, optional/religion `not_applicable` never counted, TC/DISCONTINUED বাদ। খোলা ছিল একটি ছোট অসঙ্গতি: **absent সেলের display token ভিন্ন পৃষ্ঠায় ভিন্ন** — register `AB`, result card `– absent`, detail `— (no mark entered)`, Analysis cards/subject-fail `Absent`। এছাড়া `EXAM_ABSENT_SUBJECT_FAILS=False` হলে result_sheet-এর absent ব্যাজ হার্ডকোডেড **F** দেখাত ও ফুটনোট "counted as 0" বলত — যা False path-এ সত্য নয়।

**এখন:** নীতি অপরিবর্তিত (কোনো মান/নীতি নিজে থেকে বদলানো হয়নি — D-MIS owner-সিদ্ধান্ত ২০২৬-০৯-১৭ অনুসরণ করা হয়েছে)। absent সেলের token **সব cell-প্রিন্টিং surface-এ `AB`**, False-path display সত্যভাবে render হয়, প্রদর্শন-টেবিল docs-এ নথিভুক্ত, ৬টি নতুন cross-view consistency test।

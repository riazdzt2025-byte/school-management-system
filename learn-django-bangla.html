Python — ভাষাটা শিখুন

দিন ২–৪ · দিনে ~১.৫ ঘণ্টা

Django শেখার আগে Python-এর এইটুকু জানলেই হবে। বেশি গভীরে যাবেন না।

লেসন ১.১ভেরিয়েবল ও ডেটা টাইপ

ভেরিয়েবল হলো নাম দিয়ে মান রাখার বাক্স। টাইপ মানে কী ধরনের মান — সংখ্যা, লেখা, হ্যাঁ/না।

# ভেরিয়েবল = নাম, ডানদিকে মান
name = "রহিম"        # লেখা (string)
roll = 101            # সংখ্যা (integer)
gpa = 4.85          # দশমিক (float)
is_passed = True      # হ্যাঁ/না (boolean)

print(name, roll, gpa)  # পর্দায় দেখানো
✍️ নিজে করুন: hello.py ফাইল বানিয়ে নিজের নাম, রোল লিখে চালান।

লেসন ১.২if / else — সিদ্ধান্ত নেওয়া

প্রোগ্রামকে “যদি…তাহলে…” শেখান। GPA ৫.০ হলে “A+”, না হলে “পাস”।

gpa = 4.85
if gpa >= 5.0:
    print("A+")
elif gpa >= 3.0:
    print("পাস")
else:
    print("ফেল")

⚠️ Python-এ ইনডেন্টেশন (স্পেস) খুব গুরুত্বপূর্ণ — if-এর নিচের লাইন অবশ্যই ডানদিকে সরাতে হবে।

✍️ নিজে করুন: GPA বদলে বদলে চালান, আউটপুট বদলায় কিনা দেখুন।

লেসন ১.৩লুপ — একই কাজ বারবার

১০০ জন ছাত্রের নাম ছাপতে হলে ১০০ বার লিখবেন না — লুপ করবেন।

students = ["রহিম", "করিম", "সালমা"]
for s in students:
    print(s)
✍️ নিজে করুন: ১ থেকে ১০ পর্যন্ত সংখ্যা ছাপার লুপ লিখুন (range(1, 11) ব্যবহার করুন)।

লেসন ১.৪লিস্ট ও ডিকশনারি — তথ্য জমানো

লিস্ট = অনেক মানের সারি। ডিকশনারি = নাম-মান জোড়া (একজন ছাত্রের সব তথ্য)। ডাটাবেসের ধারণা এখান থেকেই আসে।

# ডিকশনারি: একজন ছাত্র = একটি dict
student = {"name": "রহিম", "roll": 101, "class": "Six"}
print(student["name"])   # → রহিম
✍️ নিজে করুন: ৩ জন ছাত্রের ডিকশনারি বানিয়ে লুপ দিয়ে সবাইকে ছাপুন।

লেসন ১.৫ফাংশন — কাজের প্যাকেজ

একই কোড বারবার না লিখে ফাংশনে রাখুন। GPA হিসাবের মতো কাজ ফাংশনে রাখুন।

def grade(gpa):
    return "A+" if gpa >= 5.0 else "পাস"

print(grade(4.9))   # → পাস
✍️ নিজে করুন: এমন একটি ফাংশন লিখুন যা ছাত্রের নাম নিয়ে “স্বাগতম, রহিম!” ছাপে।

HTML ও CSS — পেজের চেহারা

দিন ৫ · ~১.৫ ঘণ্টা

Django পেজ বানায় HTML দিয়ে। এইটুকু জানলেই চলবে — ডিজাইনার হওয়ার দরকার নেই।

লেসন ২.১HTML কাঠামো

HTML হলো ওয়েবপেজের কাঠামো — ট্যাগ দিয়ে বোঝানো হয় কোনটা শিরোনাম, কোনটা লেখা, কোনটা বাটন।

<h1>ছাত্র তালিকা</h1>
<p>মোট ছাত্র: ১০০ জন</p>
<table>
  <tr><td>রহিম</td><td>১০১</td></tr>
</table>
✍️ নিজে করুন: test.html ফাইল বানিয়ে ব্রাউজারে খুলুন।

লেসন ২.২ফর্ম — তথ্য পাঠানোর রাস্তা

“ছাত্র যোগ করুন” ফর্মটাই এই প্রজেক্টের প্রাণ। input দিয়ে তথ্য নেওয়া হয়, button দিয়ে পাঠানো হয়।

<form method="post">
  <input name="name" placeholder="নাম">
  <input name="roll" placeholder="রোল">
  <button>যোগ করুন</button>
</form>
✍️ নিজে করুন: উপরের ফর্মটি বানিয়ে দেখুন — বাটনে ক্লিক করলে পেজ রিফ্রেশ হয়।

লেসন ২.৩CSS — রঙ ও সাজসজ্জা

CSS দিয়ে রঙ, ফন্ট, স্পেসিং ঠিক করা হয়। এই প্রজেক্টে Bootstrap ব্যবহার হয়েছে — তৈরি CSS লাইব্রেরি, তাই হাতে বেশি লিখতে হয়নি।

/* CSS: দেখতে সুন্দর করার নিয়ম */
h1 { color: green; }
button { background: blue; color: white; padding: 10px; }
✍️ নিজে করুন: আগের পেজে রঙ যোগ করুন। তারপর Bootstrap-এর btn btn-primary ক্লাস লাগিয়ে দেখুন পার্থক্য।
৩

Django — আসল কাজ

দিন ৬–৯ · দিনে ~২ ঘণ্টা

এখানেই এই প্রজেক্টের রহস্য। Django-কে মনে রাখুন MVT দিয়ে: Model → View → Template।

লেসন ৩.১Django ইনস্টল ও প্রজেক্ট তৈরি

Django হলো Python-এর তৈরি ওয়েব ফ্রেমওয়ার্ক — সার্ভার, ডাটাবেস, লগইন সব তৈরি করে দেয়।

pip install django
django-admin startproject school_system
cd school_system
python manage.py runserver   # → http://127.0.0.1:8000 খুলুন
✍️ নিজে করুন: সার্ভার চালিয়ে “Congratulations!” পেজ দেখুন।

লেসন ৩.২App — প্রজেক্টের অংশ

প্রজেক্টের প্রতিটি বিভাগ একটি App। এই প্রজেক্টে students App-এ ছাত্র, পরীক্ষা, হিসাব সব আছে।

python manage.py startapp students
✍️ নিজে করুন: App বানিয়ে settings.py-এর INSTALLED_APPS-এ যোগ করুন।

লেসন ৩.৩Model — ডাটাবেসের টেবিল

Model হলো ডাটাবেসের টেবিলের বর্ণনা। ছাত্র টেবিলে কী কী কলাম থাকবে, তা এখানে লেখা হয়।

# students/models.py
from django.db import models

class Student(models.Model):
    name = models.CharField(max_length=100)
    roll = models.IntegerField()
    klass = models.CharField(max_length=20)
✍️ নিজে করুন: Model লিখে python manage.py makemigrations ও migrate চালান।

লেসন ৩.৪View + URL — অনুরোধের উত্তর

View = অনুরোধ এলে কী করবে। URL = কোন ঠিকানায় কোন View চলবে।

# students/views.py
from django.http import HttpResponse

def home(request):
    return HttpResponse("স্বাগতম!")

# students/urls.py
from django.urls import path
from . import views

urlpatterns = [path("", views.home)]
✍️ নিজে করুন: নিজের নাম ছাপার View বানিয়ে ব্রাউজারে দেখুন।

লেসন ৩.৫Template — HTML-এ ডাটা বসানো

View ডাটা পাঠায়, Template সেটা HTML-এ বসায়। {{ }} দিয়ে মান বসানো হয়, {% %} দিয়ে লুপ/শর্ত।

<!-- list.html -->
<h1>ছাত্র তালিকা</h1>
{% for s in students %}
  <p>{{ s.name }} — রোল {{ s.roll }}</p>
{% endfor %}
✍️ নিজে করুন: ৩ জন ছাত্রের তালিকা Template দিয়ে ছাপুন।

লেসন ৩.৬CRUD — পুরো প্রজেক্টের প্রাণ

এই ৪টি কাজই ছাত্র যোগ, ফলাফল, বেতন — সবকিছুর ভিত্তি:

CRUD
Create
নতুন ছাত্র যোগ		Read
তালিকা দেখা		Update
তথ্য বদলানো		Delete
মোছা
# View-এ চারটি কাজ
Student.objects.create(name="রহিম")      # Create
Student.objects.all()                        # Read
s = Student.objects.get(roll=101); s.name="করিম"; s.save()  # Update
s.delete()                              # Delete
✍️ নিজে করুন: শেল-এ (python manage.py shell) উপরের ৪টি লাইন একে একে চালান।

লেসন ৩.৭Form — ফর্ম থেকে ডাটাবেস

Form হলো ফর্মের ডাটা যাচাই করে Model-এ পাঠানোর সেতু।

# students/forms.py
from django import forms
from .models import Student

class StudentForm(forms.ModelForm):
    class Meta:
        model = Student
        fields = ["name", "roll", "klass"]
✍️ নিজে করুন: “ছাত্র যোগ করুন” পেজ বানান — ফর্ম সাবমিট করলে ডাটাবেসে জমা হোক।

লেসন ৩.৮Admin প্যানেল — বিনামূল্যে পাওয়া

Django দেয় তৈরি অ্যাডমিন প্যানেল — কোড না লিখেই ডাটা দেখা-বদলানো যায়। এই প্রজেক্টেও আছে।

# students/admin.py
from django.contrib import admin
from .models import Student

admin.site.register(Student)
✍️ নিজে করুন: সুপারইউজার বানিয়ে /admin/ খুলুন — ছাত্রদের দেখুন।

এই প্রজেক্টের ফিচারগুলো

দিন ১০–১২ · দিনে ~২ ঘণ্টা

এখন মূল CRUD-এর ওপর এই প্রজেক্টের বিশেষ ফিচারগুলো যোগ করুন।

লেসন ৪.১লগইন ও পারমিশন

সবাই সবকিছু দেখতে পারবে না — লগইন ও গ্রুপ-ভিত্তিক অনুমতি (ভর্তি, পরীক্ষা, হিসাব) লাগানো হয়েছে।

# শুধু লগইন করা ব্যবহারকারী দেখতে পারবে

লেসন ৪.৫ফলাফল হিসাব (GPA)

বিষয়ভিত্তিক নম্বর থেকে GPA হিসাব — এটা সাধারণ Python লজিক, Django-র বাইরে।

def calculate_gpa(marks):
    total = sum(marks)
    return total / len(marks)

দিন ১৩–১৪ · ~২ ঘণ্টা

আপনার অ্যাপ ইন্টারনেটে সবার জন্য খুলে দিন — এই প্রজেক্ট Render-এ আছে।

লেসন ৫.১Git ও GitHub

Git দিয়ে কোডের সংস্করণ রাখা হয়, GitHub-এ ব্যাকআপ। এই ৩টি কমান্ডই যথেষ্ট:

git add .            # কোন ফাইলগুলো পাঠাবেন
git commit -m "বার্তা"  # সংরক্ষণ
git push           # GitHub-এ পাঠানো
✍️ নিজে করুন: GitHub-এ অ্যাকাউন্ট খুলে এই প্রজেক্টের রিপোজিটরি দেখুন।

লেসন ৫.২Render-এ ডেপ্লয়

Render-এ GitHub রিপো বাছলেই অ্যাপ লাইভ। লাগে শুধু requirements.txt (কোন টুল লাগবে তার তালিকা) ও gunicorn সার্ভার।

# requirements.txt
Django==6.1
gunicorn==26.1.0
psycopg2-binary==2.9.12
✍️ নিজে করুন: Render-এ ফ্রি অ্যাকাউন্ট খুলে নিজের ছোট অ্যাপটি লাইভ করুন।

🎓 ১৪ দিন পর আপনি কী পারবেন

নিজে একটি ছাত্র ম্যানেজমেন্ট সিস্টেম বানাতে, GitHub-এ রাখতে এবং ইন্টারনেটে লাইভ করতে। তারপর এই প্রজেক্টের কোড খুলে প্রতিটি ফাইল পড়তে পারবেন — কারণ প্রতিটি অংশ আপনি নিজে বানিয়েছেন।
